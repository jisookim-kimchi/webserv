Welcome to webserv!

If you see this page, the webserv HTTP/1.1 server is successfully running and working.

For online documentation and support, please refer to nginx.org.
Commercial support is available at nginx.com.

Features & Evaluation Routes

  • HTTP 301 Redirection to nginx.org
  • Documentation Route (301 to nginx.org)
  • Upload Directory (Autoindex enabled)
  • CGI Python Hello
  • CGI Python Echo

Upload (POST raw body)

curl -X POST --data-binary @file.txt http://127.0.0.1:8080/upload/

Delete

curl -X DELETE http://127.0.0.1:8080/upload/FILENAME

Thank you for using webserv.
